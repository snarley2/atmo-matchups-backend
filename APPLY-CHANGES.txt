Apply these changed files over the existing project, preserving their folder paths.

1. Frontend: extract frontend ZIP into the frontend project. Run npm run build and redeploy/restart the frontend.
2. Backend: extract backend ZIP into the backend project. Keep your existing environment settings. Restart/redeploy the backend with SUPABASE_DB_URL configured. The new Responsibilities tables are created automatically on first use; supabase/responsibilities.sql is included.
3. From the backend folder run: npm run update:production
   This refreshes production and appends missing Agents into Supabase. Repeated imports avoid duplicate reps. Existing attendance, trainer settings and stable rep keys are preserved. Office aliases are normalized when reading Agents.
